## Delivered behavior

Discover's optional **Coverage studies → Self-service** panel inspects a declared twelve-company sample using production financial, listing, price, peer, trend and scenario adapters. Each explicit action inspects one company. Ordinary reads revalidate saved source packets locally without network requests or snapshot writes. Recheck replaces one attempted company; restart clears only this study. Failed and unattempted cases retain their original denominator. The study's disposable save/load/unchanged rehearsal never writes user notes or user evidence stores.

Shared repairs distinguish relevant financial forms from large bank submission catalogs, event dates from fiscal durations, and safe legacy document metadata from supported statement parsing. Exact 6-K duration evidence can qualify a historical quarter or interim; newer reporting periods still prevent historical facts from being called current. Native statements take precedence over convenience USD history without currency conversion. Matched source identity remains independent of the narrower annual USD preview.

The current-context price join uses the existing peer validator's floating-point precision tolerance (`1e-7` relative / `1e-6` absolute). Price dates, completed sessions, annual diluted EPS, the 35-day fiscal window and at least three eligible industry references remain required. Oversized peer packets hold the peer lane while preserving independent financial and price results. Exact snapshots retain the existing 512 KiB bound and disclose size holds before writing.
