# FX evidence and historical currency-review goal

Capture one exact ECB USD/EUR reference for SAP's already-retained price date,
using a bounded single request in the network-enabled GitHub runner. Keep the
normal engineering/release workflow offline. Preserve original XML bytes, source
URL, SHA-256, retrieval time and optional server Last-Modified metadata. A failed
capture is unavailable evidence, never a passing source claim. No broad source
refresh, private-data upload, source-key configuration or repeated failed probe.

Validate the exact reference date, euro base, USD direction, positive decimal,
namespace and unique observation. Build a separate historical currency review
from the immutable SAP research context and exact captured bytes. Translate only
the directly reported EUR amount per ordinary share into a derived USD amount per
ordinary share at that date's reference rate. Do not relabel it as issuer-reported
USD EPS, EPS per ADS/ADR, P/E, a peer comparison or an approved valuation denominator.
Keep all existing identity, continuity, accounting and source-rights holds.

Make this an explicit personal-research action with no source calls on ordinary
render, route changes, saved replay or Monitor. Cache only for the exact original
context/profile; show original and later retrieval/review dates distinctly. Allow
a separate inspectable download containing public FX source bytes, receipt and
minimal derived review, without original notes or profile identifiers. Never put
later FX observations into the old research snapshot or its historical cutoff.
A later capture does not prove point-in-time availability or first publication.

Exercise malformed/duplicate/foreign/oversized XML, altered tokens, wrong dates,
reversed units, future times, cross-context caching and historical boundaries.
Run meaningful tests, actual source acquisition, desktop/phone workflow checks
and independent review, then sync GitHub and report exact-head CI. Do not merge,
deploy, create accounts, change credentials or contact researchers.

Following stages: review security/valuation methodology only after the evidence
supports it; operate the private pilot in a selected real host with a named owner;
then observe consented actual researchers and later return use. Templates and
AI-generated sessions cannot establish those operating or human outcomes.
